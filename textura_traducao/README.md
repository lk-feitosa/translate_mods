# 🎨 textura_traducao

Esta pasta contém o **Resource Pack de tradução** para português brasileiro.

## ℹ️ Por que não está no Git?

- Tamanho: ~15.85 MB (muito pesado, especialmente PNG)
- Conteém arquivos binários grandes (pack.png)
- Recomenda-se usar **Git LFS** (Large File Storage) se precisar versioná-lo

## 📦 Conteúdo

- `pack.mcmeta` - Metadados do resource pack
- `pack.png` - Ícone do pack (6.1 MB)
- `assets/` - Texturas, modelos e tradução de idioma

## 🚀 Como usar?

1. **Copiar para o Minecraft:**
   ```
   %appdata%\.minecraft\resourcepacks\
   ```

2. **Ativar no Minecraft:**
   - Options → Resource Packs → Ativar "Tradução PT-BR"

## 📝 Para compartilhar no GitHub

Use **Git LFS** para versionamento:
```bash
git lfs install
git lfs track "*.png"
git add .gitattributes
git commit -m "Configure Git LFS for large files"
```

---

**Nota:** Arquivo armazenado localmente. Para upload, use Git LFS ou compartilhe via cloud storage.
