# 🔧 recovered

Pasta para armazenar arquivos recuperados e arquivos de debug.

## 📋 Conteúdo

- `*.cpython-314.pyc` - Arquivos Python compilados
- `*.err` - Logs de erro
- `strings_*.txt` - Strings extraídas de bytecode

## ℹ️ Por que não está no Git?

- Conteém arquivos compilados gerados automaticamente
- Logs de erro temporários
- Não é conteúdo-fonte do projeto

## 🧹 Limpeza

Para limpar esta pasta:
```bash
rm -rf recovered/*
# Deixar apenas .gitkeep para manter a estrutura
```
